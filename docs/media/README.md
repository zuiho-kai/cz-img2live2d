# 小征演示与头发复核

首页使用 GitHub 视频附件内嵌播放器，可以直接播放、暂停和拖动进度。

- 主视频来自仓库默认预览的实际连续排练，包含待机、倾听、思考、录音口型与停止；使用 Chromium 软件渲染，不构成桌面 GPU 性能测试。
- 前后对照为 30 秒，相同随机种子、相同录音 PCM 数据、相同动作和取景。两侧按 30 Hz 同步推进控制状态，实际头部、身体和肩膀轨迹逐点一致；对照没有通过改动主体运动幅度制造差别。
- 画面取景按角色实际绘画范围计算，保留动作余量；主视频和对照都没有声音。
- [头发检查数据](hair-checks.json)记录限位、网格隔离和停止结果；这些数据不等于整体动作质量已被接受。
- 默认模型来源、文件哈希和预览方式见 [默认模型](../../examples/default-live2d/README.md)。

`changzheng-demo.gif` 是 v0.1.0 的旧版 20 秒 GIF，保留作历史对照；它不再是首页默认演示。
